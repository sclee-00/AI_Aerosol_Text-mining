# AI_Aerosol_Text-mining
**Analysis of Knowledge Structure and Research Trends in AI-based Aerosol Research Using Text Mining**

## Data Source
- Korea Citation Index (KCI)  [KCI](https://www.kci.go.kr/kciportal/main.kci)
- Web of Science (WoS)  [WoS](https://www.webofscience.com/wos/woscc/smart-search)

## Package Version
- python=3.12.13
- scikit-learn=1.9.0

## Installing required libraries
- numpy, pandas, matplotlib, seaborn, scipy, scikit-learn, networkx, rispy, Pillow, threadpoolctl
